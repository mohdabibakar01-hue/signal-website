# Signal Pro

Crypto trading signals website with a subscriber dashboard, an admin panel for posting signals, and a live chat room.

## Structure

- `public/index.html` — main site markup
- `public/styles.css` — site styling
- `public/app.js` — front-end behavior (signals, chat, subscriptions)
- `server.js` — Express API used for local development (`/api/signals`, `/api/subscribers`, `/api/chat`)

## Local development

```bash
npm install
npm run dev
```
